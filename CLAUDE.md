# tcp — The Chill Photographer

Визитка и фотоальбомы на GitHub Pages: https://olkrind.github.io/tcp/ (репозиторий `olkrind/tcp`, открытый).
Фото и видео — в Cloudflare R2, отдаёт воркер `https://tcp.olkrind.workers.dev`.
Устройство сайта, поля `content/albums.json`, команды — в `README.md`. Здесь — порядок работы.

Название сервиса, с которого переносятся альбомы, в репозитории не упоминается — ни в коде, ни в README, ни в этом файле, ни в сообщениях коммитов. Вместо него — «образец», «страница-образец».

## Контекст

- Сайт заменяет старые галереи пользователя: альбомы переносятся оттуда, внешний вид и поведение повторяют страницу-образец.
- Интерфейс сайта на английском; названия альбомов — как задал пользователь, на любом языке. Альбомы выставки Зарины — в стиле `«Мир моими глазами». Подготовка`.
- Бюджет нулевой. Сайт — GitHub Pages (~1 МБ без фото). Фото — R2 (10 ГБ бесплатно), воркер на бесплатном плане — 100 000 запросов в сутки, сверх лимита ошибка 1027 до 00:00 UTC.
- Отложено: свой домен (~$11/год) — бакет на домен без воркера и лимита, сайт на тот же домен; кнопка «Originals» (`archiveUrl`) — ссылка на папку Google Диска с оригиналами.

## Перенос альбома со страницы-образца

Пользователь присылает ссылку на альбом-образец и путь к архиву «resized» в `~/Downloads`.

1. Открыть образец в Chrome через расширение и снять в цифрах (`javascript_tool`, `getComputedStyle`): название, дата, `cover__header--small|medium|large` (→ `titleSize`), `background-position` у `.cover__image` (→ `coverPosition`), затемнение (`::after` у `.cover__image`), фон просмотра (`.pswp__bg`), есть ли скачивание, вкладки, раскладку и промежуток (класс `pieces--masonry|storyboard`, `grid--small|medium|large-pad`). Порядок файлов и места видео — из фрагмента сетки: `fetch` адреса из `src` у `turbo-frame[id^=pieces_container]`, атрибуты `title`. Вывод с URL и параметрами запроса расширение блокирует — не возвращать адреса в результате.
2. Распаковать в `photos-src/<slug>/` (`unzip -j`), `slug` — как в адресе образца. Для альбома с вкладками — подпапка на раздел, `sections[].dir`. Видео (`.MOV`) — там же; `ffprobe`: HLG (`arib-std-b67`) обработка переводит сама, длина и размер — влезет ли в разумный объём.
3. Обложка: отпечаток снять в браузере, сопоставить `node scripts/find-cover.mjs` (инструкция в начале скрипта). Расхождение выше ~10 — проверить кадр по времени съёмки в EXIF (у обложки образца EXIF сохранён). Образец обрезает обложку до своей пропорции: если `w`/`h` не 100%, обрезать копию в `photos-src/<slug>/cover.jpg` так же. Обложки нет среди фото — попросить файл у пользователя.
4. Запись в `content/albums.json` (порядок записей — порядок карточек; уточнить у пользователя), `npm run photos` (обработка и выгрузка в R2), `npm run build`.
5. Проверить в Chrome: `npm run preview -- --port 4173 --strictPort` в фоне, страница `http://localhost:4173/tcp/…`; ширина телефона — iframe 390 px внутри страницы. Сравнить с образцом в цифрах, не на глаз: заголовок, обложка, число фото и видео, места видео, подписи в просмотре. Мобильную вёрстку образец выбирает на сервере по устройству — во фрейме её не увидеть; мобильный CSS образца можно получить `curl` с мобильным User-Agent.

## Проверка и публикация

- `npm run build` включает `tsc`; ошибки языкового сервера вида «Cannot find module 'react'» после переименования папки — устаревший путь, ориентир — `tsc`.
- Коммит и пуш — только по словам пользователя. Обычно два коммита: код и альбом (`content/`, `src/generated/`); фото в git не входят — они в R2. Доработки — отдельными коммитами, чтобы их можно было откатить по одной.
- После пуша дождаться GitHub Actions и проверить опубликованный сайт `curl`-ом:
  `curl -s "https://api.github.com/repos/olkrind/tcp/actions/runs?per_page=1"` — `head_sha`, `status`, `conclusion`.
- Правка воркера — `npx wrangler deploy --config worker/wrangler.jsonc` (вход — `npx wrangler login`, его выполняет пользователь). Ключи R2 — в `.env`, вне git; значения не выводить.
- Переименование репозитория: `siteUrl` в `site.config.json`, `git remote set-url`, `name` в `package.json` и `package-lock.json`, README, локальная папка `~/workspace/Projects/<имя>`. Старый адрес Pages отдаёт 404 — предупредить про разосланные ссылки.

## Что пользователь ценит

- Сначала изучить образец через Chrome, потом делать: правки без просмотра образца пользователь отклоняет.
- Повторять образец по замерам: отступы, размеры шрифтов, эффекты наведения, положение обложки.
- После правки показывать результат в браузере и называть, что проверено, а что нет (например, Safari, телефон, «Save contact»).
- Найденные расхождения с образцом — сообщать сразу; не относящиеся к задаче — в бэклог (`docs/backlog/`) после согласия.
